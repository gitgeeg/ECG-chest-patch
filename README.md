**ADS1292R + ESP32-H2 + BMI270｜蓝牙实时广播｜**

本项目面向便携、长时间生理信号采集，设计以 PI（聚酰亚胺）柔性电路板为载体的心电呼吸监测胸贴。ADS1292R 负责单导联心电与阻抗呼吸信号采集，BMI270 提供加速度、角速度及芯片内部温度，ESP32-H2 通过蓝牙 BLE 向电脑回传数据，并接收采集控制和寄存器配置命令。

项目以低成本、可复刻、可扩展为设计目标，开放嵌入式固件与 Python 接收、处理和显示代码，提供完整的算法验证平台。

## 一、应用方向

- **长时间心电记录研究**：观察心电波形、心率及心搏间期变化，为心律相关算法提供可回溯数据。
- **睡眠呼吸研究**：同步记录阻抗呼吸、心电和体动，探索呼吸节律及睡眠相关事件的分析方法。
- **运动场景信号研究**：利用 IMU 记录体动，为后续运动伪迹识别、信号质量评估与去伪算法开发提供基础。
- **开放算法验证平台**：保存原始数据和处理结果，便于比较滤波、R 波检测、呼吸检测及 HRV 算法。

以上是应用与研究方向，不代表已具备心律失常或睡眠呼吸暂停的临床诊断能力；运动伪迹抑制也尚未实现。

## 二、硬件设计

### 柔性贴附结构

主体采用 PI 基材 FPC，面向贴附式佩戴；电极接口按湿式 Ag/AgCl（银/氯化银）心电电极设计。三电极连接用于信号测量与右腿驱动（RLD），相关输入设计有 ESD 防护。

**ESD 防护不等于除颤防护。** 当前硬件未完成除颤防护与医疗电气安全验证；如后续增加相关能力，需要完整的输入保护、隔离及测试设计，而不是仅增加一颗 TVS。

### 核心模块

| 模块 | 作用 | 当前配置 / 接口 |
| --- | --- | --- |
| ADS1292R | 心电与阻抗呼吸模拟前端 | SPI；当前固件 SPI 时钟 1 MHz |
| ESP32-H2 | 采集调度、协议封装、BLE 回传与远程控制 | RISC-V；使用 BLE |
| BMI270 | 三轴加速度、三轴角速度与内部温度 | I²C 400 kHz，地址 0x68；SDA GPIO12、SCL GPIO14、INT1 GPIO10 |

BMI270 的 VDD、VDDIO 为 3.3 V，SDO 接地，SDA/SCL 使用外部上拉。INT1 配置为低有效推挽输出，GPIO10 以下降沿触发，不依赖外部上下拉。

电池分压关系为：`电池正极 — 13 kΩ — GPIO2 — 15 kΩ — GND`，还原公式为 `Vbat = Vgpio2 × 28 / 15`。

注意：ESP32-H2 支持 BLE 与 IEEE 802.15.4，不支持 Wi-Fi，也不使用 ESP-NOW。本工程的无线传输方式明确为 **BLE**。

## 三、采集与通信架构

默认构建的是 **ECG / 呼吸 + BMI270 蓝牙整合固件**。上电初始化无线并广播 **`ECG-H2`**；电脑订阅后，心电、呼吸、IMU、电池和状态信息沿用原来的 BLE 服务与通知通道回传，不需要再连接一个 IMU 设备。

- **CH2 心电**：保留 500 SPS 的有符号 24 位 ADC 数据。
- **CH1 呼吸**：ADS 同样以 500 SPS 采集，固件对连续 10 点求块均值，以 50 SPS 回传。保存的 CH1 源数据是该块均值，并非全部 500 SPS 原始点。
- **BMI270**：加速度计 25 Hz / ±2 g，陀螺仪 25 Hz / ±2000 °/s，使用普通带宽配置；回传六轴原始值，电脑换算为 g 与 °/s。
- **温度**：每 5 秒读取 BMI270 内部温度；它反映芯片温度，**不是人体体温**。

BMI270 优先使用 GPIO10 数据就绪中断，等待 60 ms 超时后允许轮询回退，并在数据中区分 `IRQ` / `POLL`。IMU 初始化或连续读取失败时独立重试，不因 IMU 不可用而主动停止 ECG。

## 四、本地软件功能

![image.png](https://image.lceda.cn/oshwhub/pullImage/51c0e9c46b314c7cbbd0615d50d7ce07.png)
### 实时波形与分析

- 实时显示 ECG 和呼吸波形，标记 R 波与呼吸峰。
- 计算心率、呼吸频率及 HRV 指标：SDNN、RMSSD、pNN50。
- 默认只启用 **ECG 0.5 Hz 高通**与**呼吸 0.05 Hz 高通**。
- 高通、低通以及 ECG 陷波均可独立开关、调整参数；低通和陷波默认关闭。处理设置不覆盖原始数据。
- 丢样、近饱和、无效数据与设备重配置会影响检测有效性；分析不跨已识别的采集断段连接 RR 间期。

### 右侧状态区

集中展示 BLE 连接与设备采集状态、导联检测状态、各通道 ADC 使用幅度与距离饱和的余量、电池电压、IMU 六轴数值及芯片温度。

**LOFF_SENS 上电默认值为 `0x00`，导联脱落检测默认未启用。** 此时 UI 显示“未启用检测”，不能据此判断电极已经连接；远程配置启用检测后，才根据设备状态显示脱落信息。ADC 幅度状态依据源数据判断，不因显示滤波掩盖饱和。

### 远程控制

电脑可以查询配置、停止或开始 ADS 采集，以及修改以下白名单寄存器：

`RESP2`、`RESP1`、`LOFF_SENS`、`RLD_SENS`、`CH1SET`、`CH2SET`、`LOFF`。

## 背景信息：
大家好，我是 BG9PQV。今天想向大家介绍一个我已经筹备了相当长时间的项目：一款 ECG 心电胸贴。
这个项目最初是在去年三月份开始的。刚开始时，我其实没有特别明确的目标，只是因为对心电图比较感兴趣，想亲自制作一个设备，看看人体的心电信号究竟是什么样的。另外，我偶尔也会感觉到心悸，因此希望能够通过这个项目，以比较简单的方式观察和记录自己的心电信号。
项目最初使用的是 BMD101。这是一款集成度较高的单芯片心电采集方案。不过，当时能够找到的公开资料非常少。后来，我又不小心把原本给电烙铁使用的 20 V 电源接到了开发板上，最终导致芯片损坏。因此，项目被暂时搁置。
直到去年暑假，我才重新启动这个项目。在重新评估了可用器件之后，我决定改用 ADS1292R，并开始验证一套新的硬件设计。重新开始之后，项目推进得依然比较缓慢。直到今年六月，我才终于完成了初始驱动代码，并完成了最基本的功能验证。
今年暑假，我申请了嘉立创的星火计划，并开始将这套设计制作成一款完整的 ECG 心电胸贴。
在功能方面，我希望这款设备不仅能够采集心电信号，还能够结合 BMI270 六轴惯性传感器，记录与人体运动和胸壁运动相关的数据。这样一来，它就可以作为各种心电算法的验证平台，用于研究心电信号、呼吸、身体活动，以及心脏收缩所引起的胸腔微小机械振动之间的关系。
整个暑假期间，我一直在同时开发这款心电胸贴和一个短波 RF 模块。遗憾的是，这两个项目都遇到了一些挫折。在暑假的最后几周，我把主要精力转移到了另一个嵌入式电子徽章项目上。好在中秋节和国庆节连休期间，我先后完成了短波 RF 模块和心电胸贴的最后集成测试。
这意味着这一阶段的开发工作基本告一段落，也到了暂时结束这个项目的时候。
目前，这款心电胸贴已经实现了以下功能：
1.	它可以采集胸腔阻抗的变化，以及带有右腿驱动（RLD）功能的单导联 ECG 心电信号。
2.	它搭载了 BMI270 六轴惯性传感器，可以同时记录三轴加速度和三轴角速度数据。
通过这些数据，设备可以为胸腔运动检测、身体活动识别，以及心电和心脏搏动引起的胸腔机械振动相关算法提供原始数据。
目前，设备已经能够通过蓝牙稳定地传输数据，并连接到电脑或其他终端进行实时接收和记录。在续航方面，当前版本使用 400 mAh 电池时，连续工作时间至少可以达到 15 个小时，基本能够满足长时间数据采集和算法验证的需求。
